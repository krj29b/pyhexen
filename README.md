# PyHexen (working codename)

A Python reimplementation of the Hexen engine: a faithful 35 Hz fixed-point simulation with a modern OpenGL renderer (pygame-ce + moderngl).

**Status:** planning. See [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md) and [docs/PROGRESS.md](docs/PROGRESS.md).
**For AI agents:** start with [AGENTS.md](AGENTS.md).

## Requirements
- Python 3.12+, [uv](https://docs.astral.sh/uv/)
- Your own copy of `HEXEN.WAD` (for example from Steam or GOG). **Game data is not included and must never be committed.**
